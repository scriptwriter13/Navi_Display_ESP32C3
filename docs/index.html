BikeNav_C3

Open Source Navigation für dein Cockpit.

Über das Projekt

BikeNav_C3 ist ein hochoptimiertes Navigations-Display für Radfahrer. Minimalistisch, schnell und voll integriert.

Hardware

Das Projekt ist für das ESP32-2424S012 Display-Board optimiert. Dieses Board ist kostengünstig (ca. 12$) auf Plattformen wie AliExpress erhältlich.
