BikeNav_C3

Die smarte Open-Source-Navigation für dein Fahrrad.

Was ist BikeNav_C3?

Ein kompaktes, ESP32-basiertes Navigations-Display, das via Bluetooth mit deinem Smartphone kommuniziert. Minimalistisch, effizient und voll anpassbar.

Features

  • BLE-Konnektivität: Nahtlose Anbindung an Navigations-Apps.
  • OTA-Updates: Firmware-Updates direkt über Bluetooth.
  • Hardware-Flexibilität: Dynamische Touch-Erkennung (CST816S).
  • Energieeffizient: Light-Sleep Modus für lange Touren.
