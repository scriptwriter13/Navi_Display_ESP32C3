Über das Projekt About the project

Navi_Display_ESP32C3 ist ein hochoptimiertes Navigations-Display für Radfahrer. Minimalistisch, schnell und voll integriert. Die Navigation erfolgt über gängige Android-Apps wie OsmAnd, Komoot oder Google Maps. Das Display empfängt dabei via Bluetooth die Notifikationen oder Text-to-Speech (TTS) Meldungen deiner Navigations-App und zeigt diese übersichtlich an. Ein entscheidender Vorteil: Bei einem Sturz ist nur das günstige Display am Lenker gefährdet, während dein teures Smartphone sicher in der Tasche bleibt. Navi_Display_ESP32C3 is a highly optimized navigation display for cyclists. Minimalist, fast, and fully integrated. Navigation is handled via popular Android apps like OsmAnd, Komoot, or Google Maps. The display receives notifications or Text-to-Speech (TTS) messages from your navigation app via Bluetooth and displays them clearly. A key advantage: In the event of a crash, only the inexpensive display on the handlebars is at risk, while your expensive smartphone remains safe in your pocket.

Hardware Hardware

Das Projekt ist für das ESP32-2424S012 Display-Board optimiert. Dieses Board ist kostengünstig (ca. 12$) auf Plattformen wie AliExpress erhältlich. The project is optimized for the ESP32-2424S012 display board. This board is inexpensive (approx. 12$) and available on platforms like AliExpress.
